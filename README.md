# Шифр двойной перестановки

Реализация симметричного шифра двойной перестановки. Программа взлома методом MITM и исследование зависимости времени взлома от длины ключа.

### Возможности
- Шифрование текстовых файлов с двумя ключами (блоки N₁xN₁ и N₂xN₂).
- Расшифровка текстовых файлов по двум ключам.
- Взлом шифра при известном открытом тексте (атака known-plaintext) для поиска перестановок (ключей).
- Бенчмарк для замера времени взлома для разных длин ключей.
- Построение графиков для CSV бенчмарков.

### Алгоритм работы шифра
1. Текст разбивается на блоки N₁хN₁, где N₁ - длина первого ключа.
2. Внутри каждого блока переставляются столбцы, затем строки (порядок определяется ключом).
3. Результат повторно шифруется с ключом N₂ (блоки N₂ х N₂).
4. Расшифровка выполняется в обратном порядке: сначала снимается второй проход, затем первый.

### Взлом _(known-plaintext)_
Известны открытый текст P и шифротекст C, требуется найти перестановки p₁ и p₂.
Используется подход **meet-in-the-middle**, снижающий сложность с N₁! x N₂! (полный перебор) до N₁! + N₂!:
1. Для всех p₂ вычисляется промежуточный текст M = D₂(C,p₂) и складывается в хеш-таблицу.
2. Для всех p₁ вычисляется M = E₁(P,p₁) и ищется в таблице.
3. Совпадение даёт искомую пару (p₁,p₂).

### Запуск
    # шифрование / расшифровка
    python main.py

    # взлом
    python cracker.py

    # замеры времени
    python benchmark.py

    # построение графиков
    python plot.py

### Результаты исследования

Время взлома растёт **факториально** от длины ключа: при переходе от (7,7) к (8,8) время увеличивается примерно в 6 раз, а от (8,8) к (9,9) ещё в 8 раз. MITM даёт большой выигрыш в сравнении с прямым перебором, но не меняет саму природу роста.
